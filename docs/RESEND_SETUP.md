### Logo
- **URL:** `https://raw.githubusercontent.com/Elevariapp/Elevari-repotransfer/b-main/public/brand/icons/icon-128.png` (PNG: mail clients do not render SVG). It is not served from `elevari.live` because Cloudflare answers non-browser clients (which is what mail image proxies are) with a "Just a moment..." challenge, so the logo would arrive broken. Same host as the hero banner; both need the repository to stay public.
- **File:** `public/brand/icons/icon-128.png` (generated by `scripts/certification/generate-icons.mjs`)

### Hero banner
- **URL:** `https://raw.githubusercontent.com/Elevariapp/Elevari-repotransfer/b-main/public/brand/email/banner.jpg` (`bannerUrl` in `api/src/lib/email-templates/brand.ts`), a static 1200x400 render of the Elevari scene. Email clients cannot run SVG or animation.
- **File:** `public/brand/email/banner.jpg`, generated by `npm run scene:generate`; do not edit it by hand. See `docs/design/SCENE_SYSTEM.md`.
- **Layers in `layout.ts`:** solid `bannerFallbackColor` (`#7C2D12`, shown while images are blocked) < CSS `background-image` (most clients) < VML (Outlook for Windows). The wordmark and tagline are real HTML text on top.
- **After changing the art:** regenerate, merge to `b-main` (that is where the URL points) and re-check `welcome` and `bookingConfirmation` at 320, 375 and 600 px.

  checkIn: '2024-01-15',
  checkOut: '2024-01-18',
